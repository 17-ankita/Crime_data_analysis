# Crime Data Analytics Dashboard
An end-to-end data analytics and machine learning project that analyzes crime records using **Python, SQL, Streamlit, Plotly, and Machine Learning**.

## Live Demo
https://crimedataanalysis-mbvwjku5ptduzwlqddl5yk.streamlit.app/

## Project Overview
The Crime Data Analytics Dashboard is designed to study crime patterns across different cities and years. It helps identify crime trends, high-risk locations, police response efficiency, conviction patterns, property loss, and case resolution insights.
This project combines data analysis, SQL queries, visual dashboards, and machine learning concepts in one interactive web application.

## Features
- Interactive Streamlit dashboard
- City-wise crime analysis
- Crime type distribution
- Year-wise crime trend
- Severity and case status analysis
- Police response time analysis
- Property loss comparison
- SQL-based business insights
- Machine learning insights
- Dynamic filters for year, city, crime type, and severity
- Deployed live using Streamlit Cloud

## Project Modules

### 1. Data Analysis
The dataset is analyzed to understand crime records, locations, crime types, police response time, and conviction results.

### 2. SQL Insights
SQL queries are used to extract meaningful business insights such as:
- Total crimes per year
- Top cities by crime count
- Conviction rate by crime type
- Police response SLA buckets
- Case status breakdown

### 3. Dashboard
The Streamlit dashboard presents the results through interactive visualizations, KPI cards, filters, and charts.

### 4. Machine Learning Insights
The project includes ML-based analysis for:
- Conviction prediction
- Crime severity classification
- Case resolution time analysis
